# 01 — Bitácora de actividades

Registro cronológico del trabajo del Analista de Sistemas. Crear un archivo **solo en los días en que haya actividad real**.

## Organización

```text
2026/
  01-ENERO/ … 12-DICIEMBRE/
ARCHIVO-HISTORICO/
```

Nombre: `AAAA-MM-DD_BITACORA.md`

Puede usar la [plantilla de actividad](../00-ADMINISTRACION-DOCUMENTAL/03-PLANTILLAS-MARKDOWN/PLANTILLA-ACTIVIDAD.md) o un listado breve del día, con enlaces a documentos y evidencias.

Los años anteriores se guardan en `ARCHIVO-HISTORICO/` o se crea una carpeta `AAAA/` nueva cuando corresponda.
