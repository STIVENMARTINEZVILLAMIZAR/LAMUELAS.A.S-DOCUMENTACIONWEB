# 06 — Proyectos

Cada proyecto vive en una carpeta con nombre descriptivo dentro del estado actual. Al cambiar de fase, **mover** esa carpeta (no duplicarla).

## Estados

| Carpeta | Uso |
| --- | --- |
| `01-EN-PLANIFICACION/` | Alcance y diseño inicial |
| `02-EN-EJECUCION/` | Trabajo en curso |
| `03-EN-VALIDACION/` | Pruebas y aceptación |
| `04-FINALIZADOS/` | Cierre y lecciones |
| `05-SUSPENDIDOS/` | Pausados |

Estructura sugerida dentro de un proyecto (crearla cuando el proyecto exista):

```text
NOMBRE-DEL-PROYECTO/
  README.md
  ALCANCE.md
  CRONOGRAMA.md
```

Evidencias del proyecto: `08-EVIDENCIAS-Y-ADJUNTOS/`, enlazadas desde el README del proyecto.
Proyectos ya irrelevantes a largo plazo: `99-ARCHIVO-HISTORICO/PROYECTOS-ARCHIVADOS/`.
